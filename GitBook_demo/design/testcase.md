# Test Case

Under this node, users can build their testcases with the repository set up
from the Model module. Drag and drop the required node-pallet into the
workspace of a test case. Once the required nodes are selected, you can
create the steps and data required at ease.

Let's explore how to build a Testcase from scratch.

## 1. Open the new TC node created

The workspace of the Testcase loads into view.

- All the default pallets are listed under **Custom pallet**
- Any nodes chosen should be placed under the **Public flow** — the tab
  with the TC name
- The details of the node can be seen under the **Info block**

## 2. Add steps

Drag the node you need from the filtered pallet list into the flow. Each
step can be configured from the **Info** panel on the right, and the node's
current status is shown as one of the standard step states (Pass, Fail,
Blocked, and so on).

## 3. Save and deploy

Once the steps and data look right, save the case and use **Deploy &
Execution** from the left-hand navigation to run it.
